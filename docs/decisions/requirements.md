# 사용자 요구와 검토 기록

## 업무

- Photoshop에서 접합한 성벽 사진만 입력으로 사용합니다. 정사영상 좌표가 실제 측량 좌표에 맞는지는 아직 확인되지 않았습니다.
- 출력은 **돌 윤곽만**입니다. 측량사가 AutoCAD에서 검수하며, 문자·표고·치수 등을 자동화할 필요는 없습니다.
- 사진 한 장에 3~9시간이 들며 월 최소 5건, 성수기 15건 이상 수행합니다. 반복 제도 부담을 낮추는 것이 목표입니다.
- 개인 업무 보조를 먼저 검증합니다. Mac과 Windows를 쓰고, 현장 측량사는 주로 Windows·AutoCAD입니다.
- 다른 사진과 DXF 쌍이 많이 있지만 현재 샘플 사진과 사람 DXF는 정합점으로 정렬되지 않았습니다.
- 원격 AI용 키 구매를 검토할 수 있으나 서비스·예산·외부 처리 범위는 정하지 않았습니다.

## 사람이 원하는 선

- 보이는 **앞면 돌 경계**를 따르고 뒤로 파인 면을 포함해 돌출을 만들지 않습니다.
- 식생에 가려진 곳은 현장 제도 기준에 맞춰 국소 추정합니다. 근거가 부족하면 함부로 닫지 않습니다.
- 닫힌 폴리라인을 선호합니다. 열린 선도 불가능한 매몰 구간에 한해 사용할 수 있습니다.
- 잔선을 많이 남기는 것보다 실루엣을 잘 표현해야 합니다. 최소 크기·허용 편차는 아직 실험 대상입니다.

## 첫 샘플의 검토 결과

- 돌 03: 사진 정면보다 안쪽의 움푹한 구간이 위 경계에 포함되어 뾰족해진 부분을 빼길 원했습니다.
- 돌 05: 위쪽 가림 경계의 V자 홈은 식생이 없다면 일자로 이어질 것이라는 사용자의 추정이 있습니다.
- 돌 07: 아래쪽 선은 적절하므로 유지하고 윗면의 안쪽 돌출을 확인합니다.
- 전체 319개 초안은 전반적인 활용성과 돌 모양에 대해 정성적 합격을 받았습니다. 접합부·식생 가림과 일부 뾰족한 정점이 알려진 단점입니다.
- 접합부를 사진 준비에서 더 매끄럽게 붙이기, 문제 영역만 이미지 모델로 보정하기, 일부를 사람이 직접 고치기는 후속 후보입니다.

선택하지 않은 세부 면적·품질 기준을 다시 물어 개발을 막지 않습니다. 실제 작업에서 편집 시간과 수정 유형을 모으며 기준을 정합니다.
